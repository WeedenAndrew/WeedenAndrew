## Featured project: [Goblin Flip](https://github.com/WeedenAndrew/Goblin-Flip)

Goblin Flip is a fantasy coin-flip game built with Flutter for Android, with an iOS release path on the roadmap. It combines animated gameplay and custom audio with persistent game state, interruption-safe wagers, power-ups, and a security-focused commerce boundary.

![Goblin Flip gameplay](https://raw.githubusercontent.com/WeedenAndrew/Goblin-Flip/main/docs/media/goblin-flip-gameplay.gif)

### Architecture

- **Presentation:** responsive Flutter scene components, animated coin effects, menus, overlays, audio controls, and replaceable visual skins
- **Domain:** centralized game rules and explicit state-transition validation for flips, wagers, balances, streaks, and power-ups
- **Persistence:** authenticated local saves, recovery copies, and protection against invalid rollback or replayed state
- **Commerce boundary:** isolated purchase, receipt-validation, and rewarded-ad services that remain disabled until production providers are configured
- **Verification:** automated tests for gameplay transitions, persistence tampering, commerce inputs, responsive layouts, bundled assets, and Android release configuration

**Stack:** Dart, Flutter, Android SDK, secure local storage, Git, and automated Flutter testing
